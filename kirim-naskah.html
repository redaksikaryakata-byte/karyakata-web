Kirim Naskahmu

Kami menerima naskah dari semua genre — fiksi, non-fiksi, puisi, buku anak, hingga akademik. Setiap naskah akan dibaca serius oleh tim editor kami.

ALUR REVIEW

Prosesnya Simpel

1

Kirim Form

Isi form kirim naskah dengan data lengkap. Lampirkan link naskah (Google Docs / Drive) atau upload file.

2

Review 1-3 Hari

Tim editor kami mereview naskahmu. Kami beri masukan & rekomendasi paket penerbitan.

3

Lanjut Terbit

Kalau naskah disetujui, kami lanjut ke proses penerbitan. Kamu bebas pilih paket sesuai budget.

1

Info Naskah

Pastikan link bisa diakses publik (View Only).

Pilih file naskahmu

Format: DOCX, DOC, PDF. Maks. 10MB.

File akan diupload ke server kami secara aman.

2

Paket yang Diminati

Pilih paket yang paling sesuai. Nanti bisa diubah setelah review.

3

Data Pengirim

Tanya Dulu via WhatsApp

Naskahmu aman. Kami tidak akan membagikan tanpa izinmu.

SYARAT NASKAH

Sebelum Kirim

Format File

Microsoft Word (.docx) atau Google Docs. Bisa juga PDF untuk preview.

Panjang Naskah

Minimal 40 halaman (setara 10.000 kata) untuk buku. Puisi boleh lebih pendek.

Karya Asli

Naskah harus karya asli, bukan plagiat. Sertakan sumber jika ada kutipan.

Belum Pernah Diterbitkan

Naskah belum pernah diterbitkan penerbit lain (kecuali antologi atau cetak ulang).

Pertanyaan Umum

Berapa lama review naskah?

1-3 hari kerja. Kami akan hubungi kamu via WhatsApp setelah review selesai.

Apakah ada biaya review?

Tidak ada. Review naskah 100% gratis. Kamu hanya bayar kalau lanjut ke proses penerbitan.

Kalau naskah ditolak, apakah bisa kirim ulang?

Bisa. Kami akan beri masukan perbaikan. Setelah kamu revisi, kirim ulang kapan saja.

Boleh kirim lebih dari 1 naskah?

Boleh. Kirim satu form per naskah, biar tim kami bisa review masing-masing dengan teliti.

Bisa kirim naskah lewat WhatsApp saja?

Bisa. Tapi kami sarankan pakai form agar data tercatat rapi. Kalau sudah kirim via WA, tidak perlu isi form lagi.

NASKAH SIAP?

Jangan Tunda Lagi

Naskahmu layak dibaca dunia. Isi form di atas, atau langsung chat kami kalau ada pertanyaan.
