1 Pendahuluan

Karyakata.id ("kami", "milik kami") menghargai privasi setiap pengguna website dan layanan kami. Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, menyimpan, dan melindungi informasi pribadi Anda.

Dengan menggunakan layanan Karyakata.id — baik melalui website, WhatsApp, email, maupun Lynk.id — Anda menyetujui praktik yang dijelaskan dalam kebijakan ini.

Komitmen kami: Kami tidak akan pernah menjual, menyewakan, atau memperdagangkan data pribadi Anda kepada pihak ketiga untuk tujuan komersial.

2 Data yang Kami Kumpulkan

Kami mengumpulkan beberapa jenis data, tergantung interaksi Anda dengan layanan kami:

a. Data yang Anda Berikan Langsung

  • Identitas: Nama lengkap, nama pena
  • Kontak: Nomor WhatsApp, email, alamat pengiriman
  • Naskah: Judul, genre, sinopsis, file naskah (jika upload)
  • Pembayaran: Bukti transfer (nama pengirim, jumlah, tanggal)
  • Komunikasi: Isi pesan, pertanyaan, permintaan bantuan

b. Data yang Dikumpulkan Otomatis

  • Alamat IP, jenis browser, perangkat yang digunakan
  • Halaman yang dikunjungi, waktu kunjungan, durasi
  • Referral (dari mana Anda menemukan website kami)

c. Data Akun & Autentikasi

  • Email & Password: Digunakan untuk login ke Dashboard Penulis. Password disimpan dalam bentuk hash (untuk login) dan plain text (untuk keperluan reset oleh Admin).
  • Riwayat Login: Waktu login terakhir, token sesi aktif (untuk keamanan).

3 Cara Kami Menggunakan Data

Data Anda digunakan untuk:

  • Memproses pesanan — penerbitan, cetak, pengiriman buku
  • Membuat & mengelola akun penulis — login, reset password, update profil
  • Komunikasi — menghubungi Anda terkait order, review naskah, royalti
  • Verifikasi pembayaran — memastikan bukti bayar valid
  • Distribusi royalti — membayarkan royalti penjualan buku
  • Peningkatan layanan — menganalisis pola penggunaan untuk memperbaiki pengalaman
  • Marketing (opsional) — mengirim info buku baru, promo, atau event literasi (dengan persetujuan Anda)
  • Kepatuhan hukum — memenuhi kewajiban hukum yang berlaku

4 Berbagi Data dengan Pihak Ketiga

Kami tidak menjual data pribadi Anda. Namun, kami dapat membagikan data terbatas kepada:

  • Ekspedisi pengiriman (JNE, J&T, SiCepat, dll) — hanya nama, alamat, dan telepon untuk pengiriman buku
  • Penyedia layanan pembayaran (bank, QRIS, Lynk.id) — untuk memproses transaksi
  • Layanan analitik (jika digunakan) — data anonim untuk statistik website
  • Pihak berwenang — jika diwajibkan oleh hukum Indonesia

5 Cookie & Teknologi Serupa

Website kami dapat menggunakan cookie dan teknologi serupa untuk:

  • Mengingat preferensi Anda (bahasa, tampilan)
  • Menganalisis traffic dan perilaku pengunjung
  • Meningkatkan kecepatan dan performa website
  • Menyimpan sesi login penulis (via localStorage)

Anda dapat menonaktifkan cookie melalui pengaturan browser. Namun, beberapa fitur website mungkin tidak berfungsi optimal tanpa cookie.

6 Keamanan Data

Kami menerapkan langkah-langkah keamanan teknis dan organisasi untuk melindungi data Anda dari akses tidak sah, perubahan, pengungkapan, atau penghancuran:

  • Enkripsi HTTPS untuk semua komunikasi
  • Akses terbatas ke data hanya untuk tim yang berwenang
  • Password admin yang kuat dan dirotasi berkala
  • Backup data berkala
  • Token sesi login penulis yang kedaluwarsa otomatis

Meski demikian, tidak ada sistem yang 100% aman. Kami tidak dapat menjamin keamanan mutlak, tapi kami berkomitmen melakukan yang terbaik.

7 Penyimpanan Data

  • Data pesanan disimpan minimal 3 tahun untuk keperluan administrasi dan royalti
  • Data komunikasi (chat, email) disimpan selama 2 tahun
  • Data akun penulis (email, password, profil) disimpan selama akun masih aktif atau hingga permintaan penghapusan
  • Data naskah disimpan selama hubungan kerja sama berlangsung dan dapat dihapus atas permintaan penulis
  • Data analitik anonim disimpan hingga 2 tahun

8 Hak Anda

Sebagai pengguna, Anda memiliki hak untuk:

  • Mengakses — meminta salinan data pribadi yang kami simpan
  • Memperbaiki — meminta koreksi data yang tidak akurat
  • Menghapus — meminta penghapusan data (dengan batasan hukum tertentu)
  • Membatasi — meminta pembatasan pemrosesan data
  • Menolak — menolak penggunaan data untuk marketing
  • Portabilitas — meminta data dalam format yang dapat dipindahkan
  • Mengganti Password — melalui halaman Profil di Dashboard Penulis
